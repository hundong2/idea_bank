# 전자신고 파일 규격 공백 분석

확인일: 2026-08-04

## 확인 결과

공개된 국세청 안내에서는 홈택스 전자신고와 신고서 서식을 확인할 수 있었으나, 본 조사 범위에서 차기 귀속연도 종합소득세 파일변환신고용 전체 파일설명서와 오류검증표를 공식 원문으로 확보하지 못했다. 검색 결과나 과거 FAQ를 현재 규격으로 간주하지 않았다.

## 필요한 원본 산출물

- 귀속연도별 종합소득세 전자신고 파일설명서
- 레코드/서식 코드와 필수·조건부 필드 규칙
- 문자 인코딩, 바이트 폭, 행 종료, 파일명 규칙
- 레코드 순서, 건수·금액 합계, 음수/공백/0 표현
- 오류검증표와 홈택스 변환검증 프로그램 버전
- 정정/기한후/환급 신고 차이 및 첨부서식 조건

## 안전한 수령과 반영

발주처가 보유한 규격은 저장소의 Git 제외 경로로 전달하고 접근권한을 제한한다. 출처·버전·해시를 기록한 뒤 필요한 필드 정의만 코드화한다. 원문 전체를 외부 AI나 공개 이슈에 붙이지 않는다. 공식 규격과 테스트 변환 결과가 없으면 `EFileSpecUnavailable`을 유지한다.
