## 문제 정의와 제안 제품

운영 중인 세무 시스템이 호출할 수 있는 Python 모듈로 근로소득, 사업자등록 없는 인적용역 사업소득, 두 소득의 겸업 사례를 판정하고 종합소득세를 계산한다. 계산 결과를 전자신고 레코드로 변환하는 경계도 제공한다. 화면, 스크래핑, 제출 연동, 배포는 범위 밖이다.

현재 구현은 **2025년 귀속 계산 커널의 1차 기준선**이다. 국세청의 해당 연도 전자신고 파일설명서가 제공되기 전에는 제출용 파일 생성을 의도적으로 거부한다. 2026년 귀속 규칙은 공식 확정 자료 검토 후 별도 규칙 파일로 추가해야 한다.

## 목표 사용자와 사용 시나리오

- 호출자: 발주처 기존 백엔드 개발자 및 세무 검증 담당자
- 입력: 홈택스 등에서 이미 정규화한 연간 근로·인적용역 소득, 공제, 세액공제, 기납부세액
- 출력: 판정 결과, 계산 명세, 경고/검토 사유, 전자신고용 정규화 페이로드
- 제출 파일: 승인된 연도별 스키마를 런타임에 명시적으로 주입한 경우에만 생성

## 현재 작업 상태

`foundation` — 도메인 모델, 대상 판정, 2025년 귀속 핵심 계산, 규칙 버전 관리, 정규화 페이로드와 고정폭 파일 엔진, 단위 테스트가 있다. 완전한 신고 자동화로 간주하면 안 된다.

## 핵심 가설과 미해결 질문

- **확립:** 근로소득과 계속·반복적인 3.3% 인적용역 사업소득은 합산 신고 대상이 될 수 있다.
- **확립:** 2025년 귀속 종합소득세 기본세율과 근로소득공제 구간은 공개된 국세청/법령 자료로 확인했다.
- **가설:** 호출 시스템은 공제·감면 및 지급명세서 항목을 신고서 단위로 정규화할 수 있다.
- **미확인:** 차기 귀속연도의 전자신고 파일설명서, 레코드 코드, 인코딩, 오류검증표, 테스트 제출 환경.
- **미확인:** 대상 업종코드별 단순경비율과 적용자격 판정에 필요한 직전연도 수입금액 등 원천 필드.
- **결정 필요:** 국세 전자신고만 생성할지, 개인지방소득세 신고 데이터도 별도 산출할지.

## 빠른 시작

```python
from krtax import TaxCase, WageIncome, calculate

result = calculate(
    TaxCase(
        tax_year=2025,
        wage=WageIncome(gross_pay=50_000_000, withheld_income_tax=1_000_000),
        income_deductions=1_500_000,
    )
)
print(result.balance_due)  # 음수이면 국세 환급 예상액
```
