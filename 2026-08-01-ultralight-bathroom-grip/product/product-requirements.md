# 제품 요구사항 문서(PRD)

## 1. 제품 정의

**DryGrip Feather**는 기존 욕실 타일 또는 욕조의 깨끗하고 건조한 표면에 직접 부착하는 초박형·초경량 미끄럼 방지 모듈이다. 항균제를 방출해 곰팡이를 죽이는 방식이 아니라, 비다공성 저영양 재료, 물막을 끊는 미세 패턴, 막힘 없는 표면 채널, 봉인형 가장자리와 세척 가능한 형상으로 미끄럼과 곰팡이 발생 조건을 줄이는 것을 목표로 한다.

## 2. MVP 범위

### 포함

- 유광 세라믹 타일용 25 mm × 75 mm 캡슐형 스티커
- 투명 또는 반투명 저밀도 폴리올레핀계 상면
- 비관통 배수 채널과 둥근 미세 돌기
- 내수성 아크릴 PSA와 박리지
- 설치 가이드와 교체 기준

### 제외

- 줄눈, 깨진 타일, 다공성 석재, 상시 침수 표면
- 이미 곰팡이나 비누막이 심한 표면에 대한 직접 설치
- 살균·소독·감염 예방 주장
- 영구 구조재 또는 건축 방수 기능
- 아동용 완구, 의료기기 또는 식품 접촉 용도

## 3. 성능 목표

아래 수치는 실험 전 **개발 목표**이며 합격 인증이나 실측값이 아니다.

| 영역 | MVP 목표 | 검증 방법 |
|---|---:|---|
| 모듈 질량 | ≤1.0 g/개 | 0.001 g 분해능 저울, n=10 |
| 완제품 면적중량 | ≤450 g/m² | 실측 질량/실측 면적 |
| 총 두께 | ≤0.65 mm | 두께 게이지, 돌기 포함 |
| 설치시간 | 20개 기준 ≤10분 | 초보 사용자 과업 시험 |
| 설치 성공률 | ≥90% | 기포·주름·초기 들뜸 없는 비율 |
| 젖은 마찰 | 원 타일보다 유의하게 개선하고 EN 16165 적용 등급 목표를 시험기관과 확정 | 공인 또는 검증된 램프/마찰 시험 |
| 맨발 편안함 | 통증 중앙값 ≤2/10 | 윤리·안전 검토 후 사용자 시험 |
| 초기 180° 박리 | 기재별 목표범위 설정 | ASTM D903 기반 비교시험 |
| 습열 후 접착 유지 | 초기의 ≥80% | 40 °C 고습/침수 사이클 후 박리 |
| 모서리 들뜸 | 1 mm 초과 시편 ≤10% | 샤워·세척 모사 후 이미지 측정 |
| 건조시간 | 평면 대조재 대비 ≥25% 단축 | 정량 살수 후 잔수 질량/영상 |
| 곰팡이 저항 | ISO 846/ASTM G21에서 상용 대조재 이상 | 외부 시험기관, 완제품 평가 |
| 세척 내구성 | 1,000회 문지름 후 기능 유지 | 질량·색·마찰·표면 검사 |
| 제한물질 | 목표 시장의 적용 규정 충족 | 공급망 자료 + 제3자 분석 |

절대 마찰 합격값은 시험법마다 결과와 의미가 다르므로 하나의 계수를 여러 표준에 혼용하지 않는다.

## 4. 재료 요구사항

- 베이스는 비다공성, 저밀도, 무가소제 또는 가소제 최소화 등급을 우선한다.
- 원료 공급자는 SDS, 성분/제한물질 선언, 로트 추적정보를 제공해야 한다.
- 의도적으로 첨가한 살생물제, 은나노, 유기주석, PFAS는 MVP에서 허용하지 않는다.
- 맨발 접촉면에는 날카로운 광물 입자나 쉽게 탈락하는 충전재를 사용하지 않는다.
- 점착제는 물, 희석 중성세제, 일반적인 욕실 온도 사이클에서 기능을 유지해야 한다.
- 색소·인쇄·교체 표시층을 추가하면 해당 층의 용출과 마모입자를 다시 평가한다.

## 5. 형태 요구사항

- 모든 외곽 모서리는 둥글게 처리한다.
- 표면 채널은 외곽까지 연결되고 세척도구가 닿지 않는 폐쇄 포켓을 만들지 않는다.
- 관통공은 하부 수분침투 위험 때문에 기본안에서 제외한다.
- 모듈 사이 간격은 배수와 발 접촉을 모두 고려하여 설치 지그 또는 종이 템플릿으로 안내한다.
- 제품 가장자리 단차가 발가락 걸림이나 박리 시작점이 되지 않아야 한다.

## 6. 사용자 경험

설치 순서:

1. 기존 곰팡이와 비누막 제거
2. 물로 헹군 뒤 완전 건조
3. 제공된 배치 템플릿 부착
4. 박리지를 제거하고 중앙에서 바깥쪽으로 압착
5. 공급자 시험으로 정한 양생시간 동안 물 사용 금지
6. 정기 청소 및 모서리 상태 점검

들뜸, 찢김, 날카로운 마모, 변색 또는 점착층 노출이 보이면 즉시 교체하도록 안내한다.

## 7. 주장과 라벨 원칙

시험 전 금지 문구:

- “곰팡이가 절대 생기지 않습니다”
- “100% 무독성/완전 무해”
- “낙상을 완전히 방지합니다”
- “살균/항균으로 가족 건강을 보호합니다”

시험 후 가능한 표현 예시:

- “ISO 846:2019의 명시 조건에서 시험한 곰팡이 저항성”
- “완제품 질량 0.9 g/개(시험 로트 평균)”
- “젖은 맨발 시험 결과와 적용 등급”
- “살생물제를 의도적으로 첨가하지 않은 수동형 배수 설계”

표현은 목표 시장의 표시광고·제품안전 규정 검토 후 확정한다.

## 8. 상용화 단계 게이트

- Gate A: 재료 쿠폰의 마찰·세척·질량 스크리닝 통과
- Gate B: 점착 적층체의 습열·세척·모서리 박리 통과
- Gate C: 외부 곰팡이 저항 및 젖은 맨발 시험 통과
- Gate D: 제한물질, 표시, 포장 및 국내 규제 검토 완료
- Gate E: 소규모 현장시험에서 중대한 들뜸·피부 불편·낙상 사고 없음
